Lecture 01Intro to Agentic Systems — 智能体系统导论

课程安排；智能体的历史（1973 ACTOR → RL 时代 → LLM 时代 → ReAct/ChatGPT/GPT-4/BabyAGI/AutoGPT）； 智能体架构（LLM 核心、规划与推理、记忆、工具、环境）；复合 AI 系统（RAG、工具使用、MCP）； 关键挑战（可靠性、训练、长程、安全、评测）。

Lecture 02LLMs for Builders — 面向智能体构建者的语言模型

语言模型基础与 LLM Stack；架构（tokenization、transformer 注意力，含 linear/hybrid attention 与上下文长度）； 训练（预训练到后训练流水线：SFT、RLHF）；推理（性能优化与 test-time scaling）； 面向智能体的 LLM（结构化 I/O 与约束解码、工具调用、上下文工程）。

Lecture 03Building Blocks: Retrieval-Augmented Generation (RAG)

RAG 动机（grounding 与幻觉）；RAG 流水线（RAG-Sequence/Token、Naive/Advanced/Modular RAG）； 索引构建（嵌入、四种分块策略、上下文检索、Late Chunking、RAPTOR、GraphRAG、HNSW）； 检索（BM25、DPR、Bi/Cross-encoder、ColBERT 延迟交互、RRF 混合检索）； 智能体化 RAG（Self-RAG、CRAG、Search-R1）；失效模式。
