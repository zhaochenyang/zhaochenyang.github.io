📱 App Store 搜索「FileFind」即可下载

为什么需要它

⚡️

毫秒级即输即搜

基于 SQLite FTS5 + trigram 的索引内核，文件名 / 路径边打边出结果，告别 Spotlight 的转圈等待。

📄

内容全文检索

不止搜文件名——文本、代码、PDF、Office 文档的正文内容都能搜，命中片段以【】展示并高亮。

🔄

实时增量更新

FSEvents 监听指定文件夹，新建 / 改名 / 删除即时同步进索引，永远搜到最新状态。

🀄

拼音搜索

输入全拼 baogao 找到「报告」，输入首字母 jsfa 找到「建设方案」——中文用户的刚需。

🖥

原生 GUI + CLI 双形态

SwiftUI 独立窗口：即输即搜、关键词高亮（中文友好）、结果表含名称/大小/时间/路径；命令行内核可脚本化。

🔒

隐私安全

索引全部存在本地，不联网、不上传、无账号。零外部依赖，只用系统自带 SQLite。

界面一览

内容全文检索：右侧预览命中片段高亮
高级筛选：名称 / 大小 / 修改时间 / 路径
