本页目标（约30分钟）：学完你能——①说出身体反应的四大系统（呼吸/循环/消化/姿态）各举一个可测量的原子；②把任意一个动作拆成"准备动作—进行动作—中断动作"三型；③在八个身体部位（手/眼/肩/脚/背/喉咙/牙/肚子）里挑最合适的一个来写当下情境；④给任意一条动作配上"次数—幅度—速度"中至少两个量词；⑤把"我紧张地做了某事"改写成可被计时、可被计数、可被测量的句子。

怎么用本页：这是调用率最高的一页——情绪页、场景页、对话页都要从这里取料。先把每个部位的"事实版"背下来，写作时按情境挑一个，不要四个部位一起上。本页和写作习作课第5章「慢镜头」是同一套方法的两面：慢镜头讲时间怎么拉长，本页讲身体怎么分到部位。

一、身体的四类反应

呼吸、循环、消化、姿态——四套系统，比"心跳"细得多

呼吸 / 循环 / 消化 / 姿态：身体的四套钟表

"心跳"是初学者写身体反应时的全部家当——其实身体至少有四套独立运行的钟表：呼吸表（肺）、循环表（血管）、消化表（肠胃）、姿态表（肌肉张力）。情绪一上来，四套钟表的反应往往不一样——呼吸加快但循环变慢（紧张发白），消化停摆但姿态绷紧（忍住呕吐）。剂量：四类反应一篇只用两类就够；用三类以上读者会觉得在看体检报告。

二、动作链的三型

任何一个动作都是三截——前、中、断

准备动作 / 进行动作 / 中断动作：把一个动作拍成三帧

"他拿起笔写下名字"是一句话，但其实是三截动作的链：伸手（准备）—握笔（进行）—写（进行）—收笔（中断）—放下（结束）。中间任何一截被打断，都会出现中断动作——手悬着、笔停在纸上、突然松手。写动作链的关键是让读者看见中间断掉的那一截，断处才有张力。剂量：一篇里动作链用 1–2 条，三型不要连用——断处出现一次即够。

手伸到一半，停在桌面；
手指合过去，碰上杯沿又缩回；
椅子拉出两寸，没坐下。		 他犹豫了一会儿，没有去拿。 "犹豫"是心理的告知。三个原子是准备动作的三种中断——悬、碰又缩、没坐——准备动作的特征不在犹豫，在启动到一半被截断：写到"又缩回"，读者才知道他走神还是改主意。 被叫起来没准备好、答不出问题、想把话说出口又咽下。把"碰上杯沿又缩回"读出来，读者立刻知道手自己做了决定。
话说一半，声音掉下来；
字写到最后三笔，停了；
笑到一半，咬住下唇。		 他话说到一半突然不说了。 "突然不说"是省略。三个原子是进行动作的三种中断——声掉、停笔、咬住——进行动作的特征不在停，在断在哪里：声断在中段、笔停在最后三笔、笑停在嘴半开——截断的位置决定了情绪的形状。 说不出口、写不下去、笑不下去。把"停最后三笔"读出来，读者立刻知道是差一点点没完成。
门开了，又关上；
杯子举到嘴边，又放下；
手抬起来，没落在肩上。		 他犹豫了一下，最终没有做。 "犹豫了一下"是虚词，"最终没有"是结论。三个原子是动作的来回循环——开又关、举又放、抬又落——中断的特征不在没做，在做完一半再退回原位，读者能看见能量往哪里散去。 写想走近又退走、想开口又沉默、想伸手又放下。把"开又关"读出来，读者立刻知道身体已经做了又否了。

推开，再拉回来。		 他反复了好几次才决定。 "反复了好几次"是次数不清。三个原子是动作链节奏的拉长——握-松、停-写、推、拉——三型联用的特征不在多，在拍子：每一截都给了具体时间或状态，读者跟着走一遍才到结论。 写决定、签字、上场、表白。把"停了三秒再写"读出来，读者立刻知道中间那段空白是有重量的。

三、常用身体部位词库

八个部位，挑最合适的一个来写当下情境

手 / 眼 / 肩 / 脚 / 背 / 喉咙 / 牙 / 肚子

身体反应不会同时发生在八个部位——每种情境都对应最该写的那一个：紧张多半在手指和呼吸；害羞多半在脖子和脸；害怕多半在脚和肩膀；忍住不哭多半在喉咙和肚子。剂量：一次只写一个部位；写两个以上的部位属于炫耀技能。本节按对偶拆成四行——前四个部位（手/眼/肩/脚）是通用项，后四个（背/喉咙/牙/肚子）是常被漏项，写作时挑当时情境最合适的那一组用。

指节攥得发白；

眼珠定在桌角；

眼角堆起细密的褶子。		 我紧张地搓着手，眼睛不敢看他。 "搓着手"和"不敢看"都是动作或心理的标签。手写指节、眼写眼珠——两处都用具体部位代替笼统的"紧张"，读者读到指节发白才知道是哪一段在用力，读到眼珠定住才知道他在看哪里。 紧张、思考、犹豫、撒谎。眼是最通用的部位——几乎所有情绪都能从这里取料；手是最稳的部位——任何情境都不会写错。
肩比耳垂高了半寸；

耸肩的那侧先放下；
脚尖在地上点了三下；
脚往后退了半步；
脚趾在鞋里抠了一下。		 他紧张得肩膀都缩起来了，脚也在抖。 "肩膀缩起来"和"脚在抖"都是动作的标签。肩写高度差，脚写可听见的声音——两处都用可见的形状代替"紧张地动"，读者立刻知道身体在两处同时反应；脚的特征是隐蔽：脚能做多件事但常被衣摆遮住，写"脚在鞋里抠"读者才知道身体在偷偷释放。 紧张、寒冷、害怕、被突然叫名。肩部反应比脸部早半秒，是紧张最可靠的第一拍；脚比手更诚实，因为脚通常被遮住。

四、动作的量词化

给动作装三个量——次数、幅度、速度——动作立刻可被看见

次数 / 幅度 / 速度：把动作装进钟表

动作写得生动的人，不是动作本身多，而是动作被人看见。"他反复敲门"读者要靠想象，"他敲了三下，停了，又敲两下"读者直接听见。任何动作带上次数、幅度、速度三个量里的至少两个，动作就从形容词变成了现场。 剂量：三个量里挑两个用，不要三个都上；三量齐用反而显得笨拙。

原子（可背）弱版（不要写）为什么有效什么时候用
笔帽拔下来又按回去，来回了三次；
同一道题读了两遍，第二遍比第一遍快；
敲门敲了四下，门没开，再敲三下；
数到十，才敢抬头。		 他反复做了好几次。 "反复好几次"是次数不清。四组原子是可被计数的次数与对比——三次、两遍、四下、十秒——次数的特征不在多，在被听见：写到第二遍比第一遍快，读者才听见节奏变了。 紧张、等待、犹豫、重复劳动。所有"反复"都可以换成一个具体数字 + 一个对照。
抬头纹比平时深一道；
笑的时候，眼角推到了太阳穴；
摆手摆到肩平；
弯腰弯到了桌面。		 他笑了笑，幅度特别大。 "幅度特别大"是副词的告知。四组原子是可比较的幅度参数——深一道、推到太阳穴、肩平、桌面——幅度的特征不在大，在参照物：写到"眼角推到太阳穴"读者才知道笑了多大幅度。 夸张的笑、夸张的怒、夸张的恭敬。把"推到太阳穴"读出来，读者立刻知道笑是从脸中部开始。
眨眼比平时慢半拍；
说话的速度比上句慢了一倍；
走路的节拍比记忆里慢两档；
呼吸停了一拍才续上。		 他的动作变得很慢。 "变得很慢"是速度的告知。四组原子是可比较的速度参数——慢半拍、慢一倍、慢两档、停一拍——速度的特征不在慢，在与上一拍的差：写到"比上句慢一倍"读者才知道时间被拖长了。 震惊、被一句话击中、被叫起来回答、写时间被拉长的瞬间。把"慢两档"读出来，读者立刻感到时间在变形。
敲门三下，等了三秒，再敲两下；
抬手半尺，停了一秒才拍下；
转身半圈，又转回来；
吸气三口，才憋得住下一句。		 他敲门敲了很久才停。 "敲了很久"是模糊时段。四组原子是三量联用的刻度——数+速+幅度——三量联用的特征不在多，在三个量都在：写到"三下、等三秒、再两下"读者才知道时间和动作同时被截断。 写犹豫、写等待、写关键一拍。三量齐用只用在最重要的那一拍——其他位置会显得笨拙。

  • "速度"的特征在哪里？为什么必须配一个对比？
    • 📌 本页要点速览：身体反应有四套独立钟表——呼吸（肺）、循环（血管）、消化（肠胃）、姿态（肌肉）。情绪一上来四套表反应不一样：紧张会让呼吸变乱+循环撤退+姿态绷紧+消化挤住，所以写"紧张"用四套里挑两套就够了。动作是三截的链——准备动作、进行动作、中断动作，中断动作最有戏：伸到一半停、话说一半掉、笑到一半咬——断在哪里决定情绪的形状。身体有八个常用部位（手/眼/肩/脚/背/喉咙/牙/肚子），一次只写一个；写"指节攥白"比写"紧张地搓手"高级十倍，写"脚在鞋里抠"读者才知道身体在偷偷释放。动作的三个量是次数、幅度、速度，写任何一个动作都至少给两个量："敲门三下，等了三秒"已经足够，"反复敲了很久"等于没写。本页和表情页的区别：表情页写哪块肌肉动了，本页写动作的拍子（截断的位置）和身体的钟表（哪一套在工作）；两页合用是最强的搭配，但合用时各取一组即可，不要全照搬。本页用量上限和总论页三条使用禁令一致：同一篇里四套反应只用两套，八个部位只用一两个，三个量只用两个——克制本身就是技术。
